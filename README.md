# Nestly

Projecte personal, local i manual per gestionar la preparació de l’arribada d’un nadó, desenvolupat com a pràctica d’enginyeria de software assistida per IA.

M0 — Fonaments tècnics mínims i shell està completada, amb tots els criteris obligatoris verificats. La següent fita és M1 — Registrar i consultar Items que ja són a casa; encara no s’ha iniciat. Les pàgines internes actuals són placeholders, sense funcionalitat de negoci.

Consulta [Arrencada local](docs/arrencada-local.md) per als requisits, la primera instal·lació, les migracions manuals, `npm run dev` i l’aturada amb `Ctrl+C`. L’estat i les evidències dels increments es mantenen al [pla d’implementació V1](docs/pla-implementacio-v1.md).

Les fonts de context són [AGENTS.md](AGENTS.md) i [Arquitectura V1](docs/arquitectura-v1.md), amb els enllaços a requisits, domini, casos d’ús i UI/UX.
